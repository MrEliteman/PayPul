# Мои траты — версия 1.5.0 (Flutter)

Универсальные категории для любого возраста, своя категория по вкусу, поиск
по истории, простая статистика, лимит на месяц. Шрифты — Space Grotesk
(заголовки/цифры) + Plus Jakarta Sans (текст) — характерный современный
геометричный гротеск, как у необанков.

## Новое в 1.5.0
- **Копилка** — новый раздел: ставишь цель, вносишь взносы, минималистичный
  стеклянный поросёнок наполняется золотыми монетами по мере прогресса,
  плюс советы по накоплению
- **Долги** — новый раздел с двумя подразделами "Мне должны" / "Я должен":
  имя, сумма, дата, комментарий
- **Отмена удаления** — смахнул трату/взнос/долг — 4 секунды на "Отменить"
  во всплывающем уведомлении
- **Тема "как в системе"** — теперь три варианта (Системная/Светлая/Тёмная)
  вместо простого переключателя
- **Быстрые действия с иконки** — долгий тап по иконке на рабочем столе →
  сразу выбор категории и добавление траты, без захода в приложение
- Внизу экрана появилась навигация по разделам: Траты / Копилка / Долги

## В 1.4.0
- **Уведомления о лимите**: спокойное предупреждение при достижении 80%
  месячного лимита, и более заметное — при его превышении. У каждого своя
  вибрация и собственный короткий звук (не системный, специально записанный
  двухтональный сигнал)
- **Размер шрифта**: три варианта (маленький/обычный/крупный), выбирается
  в настройках, сохраняется между запусками

## В 1.3.0
- **Локальное хранилище**: язык, тема, валюта, лимит, свои категории и вся
  история трат теперь сохраняются на устройстве — при следующем запуске
  ничего не нужно настраивать заново
- **10 валют** — по одной на каждый из 10 языков приложения (RUB, USD, AZN,
  TRY, EUR×3 — Испания/Франция/Германия, SAR, CNY, BRL), переключаются
  флажком-иконкой в шапке рядом с языком
- **Новый шрифт**: Space Grotesk + Plus Jakarta Sans вместо Unbounded/Manrope
  — более характерный, "дизайнерский" стиль

## В 1.2.1
- 10 языков: русский, English, Azərbaycan, Türkçe, Español, Français,
  Deutsch, العربية, 中文, Português

## В 1.2.0
- Светлая / тёмная тема — переключается иконкой солнца/луны в шапке
- Настоящий стеклянный эффект (блюр фона) на главной карточке

## Структура проекта

```
lib/
  main.dart          — точка входа, тема и шрифты, запуск уведомлений
  models.dart         — категории, траты, копилка, долги
  donut_painter.dart  — кольцевая диаграмма (вкладка Траты)
  piggy_painter.dart   — стеклянный поросёнок-копилка (вкладка Копилка)
  localization.dart   — переводы интерфейса на 10 языков
  currencies.dart      — 10 валют, привязанных к языкам
  storage.dart         — локальное хранилище настроек и данных
  notifications.dart   — уведомления о лимите (80% и превышение)
  home_page.dart      — три вкладки: Траты / Копилка / Долги
native_sound/
  limit_alert.wav      — звук уведомления (копируется в APK при сборке)
pubspec.yaml          — зависимости (google_fonts, shared_preferences,
                         flutter_local_notifications, quick_actions)
```

## Как запустить

1. Установи Flutter (если ещё нет): https://docs.flutter.dev/get-started/install
   Проверить, что всё встало: `flutter doctor`

2. В папке проекта:
   ```
   flutter pub get
   flutter run
   ```
   Запустится на подключённом телефоне, эмуляторе или в Chrome.

## Как собрать APK

```
flutter build apk --release
```

Готовый файл появится в:
```
build/app/outputs/flutter-apk/app-release.apk
```

Просто скопируй его на телефон и установи (может понадобиться разрешить
установку из "неизвестных источников" в настройках Android).

## Что внутри (функции)

- 12 готовых категорий на все случаи жизни (еда, транспорт, жильё, здоровье,
  учёба, подарки, питомцы и т.д.)
- Кнопка "Своя" — можно создать любую свою категорию с иконкой и цветом
- Переключатель периода: неделя / месяц / всё время
- Кольцевая диаграмма расходов по категориям с процентами
- Лимит на месяц с индикатором "сколько осталось"
- Простая статистика: средний расход в день, самая затратная категория
- Поиск по истории (по названию категории или комментарию)
- Свайп по трате влево — удалить
